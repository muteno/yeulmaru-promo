# 조언 회차 원장 (AI 홍보 자동 총론 브리핑 · 260806)

- **무엇**: `promo-advise.yml`(유일한 기록자)이 성공 회차마다 1줄(JSONL) 적재 — {ts · 팩 절대값(key) · 총론·제안 압축 · model/effort}.
- **왜**: 다음 회차가 최근 2회차를 프롬프트 입력으로 받아 「지난 제안이 실행됐나(홍보 이력 대조) · 판매가 반응했나(그때→지금 수치)」를 평가하는 폐루프(운영자 260806 「아이디어도 배선」).
- **샤딩**: 월별 `YYYY-MM.jsonl`. Δ·트렌드는 굽지 않는다 — 절대값+타임스탬프만(분석은 소비 시점 몫 · nomute algo_runs 문법).
- ⚠ **기계산출물 — 손편집 금지.** 값이 이상하면 promo-advise.yml의 적재부를 고치고 다음 회차부터 반영.
