## 1. 당신의 임무

GS칼텍스 예울마루(여수 문화예술공원)의 **사업·홍보 조회 대시보드** 웹 앱을 만든다.
원본은 26,000줄 단일 HTML 앱이며, 당신은 그중 **1차 범위(조회 전용)** 를 첨부 데이터 기반으로 재구현한다.

- **진입 = PIN 게이트 한 장뿐** (§3-⓪). **팀즈/Microsoft 로그인 등 외부 플랫폼 인증은 절대 만들지 마라**
  — 타 플랫폼 승인이 필요한 기능은 전부 후순위로 분리됐다(운영자 결정, §6).
- **데이터 = 첨부된 CSV가 전부.** 데이터를 창작·추정·보충하지 마라. 없으면 "데이터 없음"으로 표시.
- 모든 UI 텍스트는 **한국어**.
- 1차 범위에 **쓰기(등록·수정·삭제) 기능은 없다.** 조회·검색·필터만.

## 3. 화면 구성 (1차 범위)

### ⓪ 진입 화면 (첫 화면 — PIN 게이트)
- 페이지 배경(§2 그라데이션) 위에 글래스 카드 하나. 카드 안: "예울마루" 타이틀 + **PIN 4자리 입력 4칸**(입력마다 도트 채움).
- 입력값이 **`0510`(슈퍼키)** 이면 대시보드 진입. 틀리면 카드 흔들림 + `#E24B4A` 색 안내문("PIN이 올바르지 않습니다") 후 초기화.
- 계정 선택·아이디·비밀번호·팀즈 로그인 등 다른 단계는 **없다.** 세션 내 유지(새로고침 시 재입력은 허용).

이후 본문: 상단 내비 1줄(로고 "예울마루" + 메뉴 탭) + 본문. 메뉴 4개:

### ① 홍보 캘린더 (기본 화면)
- 월간 그리드. `records.csv`의 행을 날짜(`날짜` 또는 `연도`·`월`·`일`)별 뱃지로 표시.
- 뱃지 텍스트 = `콘텐츠 제목`(없으면 `프로그램`), 뱃지 색 = `진행 상태`:
  완료 `#1A6B3C` · 취소/반려 `#E24B4A` · 신청 중/보류 `#D88455` · 예정/승인 `#4A4DE7` (전부 연한 alpha 배경 + 진한 글자)
- `special.csv`(담당자 특별일정: 교육·휴가·출장·회의)는 회색 계열 뱃지로 병기.
- 뱃지 클릭 → 상세 모달(해당 행의 주요 필드 표). 월 이동 ‹ › 버튼. 오늘 셀 강조.

### ② 프로그램
- `programs.csv` 카드 목록: `풀네임`, 기간(`시작일`~`종료일`), `장소`, `담당자`, `콘텐츠구분`.
- 판매 중(오늘이 `판매시작일`~`판매종료일` 사이) 배지 표시. 구분별 필터 칩.

### ③ 사업 실적
- 공연: `ops_공연마스터.csv`(사업 목록·목표점유율·상태) + `ops_일일입력.csv`(일일 판매: 기준일자·좌석·금액·점유율, `공연ID`로 조인). 사업 선택 → 일일 추이 라인 차트 + 누계 KPI(유료·매출·점유율).
- 전시: `exhib_master.csv`(전시 목록·목표·최종실적) + `exhib_daily.csv`(일일, `전시ID` 조인).
- ⚠️ **점유율 = 목표 달성률**(100% 초과 가능). "좌석 점유율"이라고 쓰지 마라.
- 차트 색 = §2 카테고리 6색 순서. 단일 시리즈는 `#4A4DE7`.

### ④ 규정 검색 (첨부 시)
- `rules.csv`(규정명·조항·제목·본문·키워드) 키워드 검색 → 조항 카드 목록. 901행이므로 검색 우선, 전체 나열 금지.

## 4. 데이터 해석 규칙 (함정 — 실제 사고 전례)

1. **신청자 ≠ 게시 담당자**: `records.csv`의 `신청자` 열이 신청 본인이다. "누가 신청했나"는 전부 `신청자` 기준. `게시 담당자`는 지정값(“상관 없음” 가능)이므로 표시 주체로 쓰지 마라.
2. 날짜가 **엑셀 시리얼 숫자**(예: 46000대 정수)로 든 열이 있다 — 시리얼이면 `(값-25569)*86400*1000` = UTC ms로 변환. 문자열 날짜(`YYYY-MM-DD…`)는 그대로 파싱.
3. `records.csv`의 `진행 상태` 값 집합: 신청 중 · 예정(승인) · 완료 · 보류 · 취소 · 반려 · 임시(임시저장 — **화면에 표시하지 마라**).
4. 홍보 노출 기간 = `programs.csv`의 `홍보시작일` ~ `판매종료일`(판매종료일 비면 `종료일`). "홍보종료일"이라는 개념은 폐지됐다 — 만들지 마라.
5. `managers.csv`는 이미 개인정보(PIN·비밀번호·이메일)가 제거된 판이다. 있는 열만 쓰고 연락처를 창작하지 마라.
6. 빈 문자열 = 값 없음. 행 전체가 빈 행은 무시.

## 5. 완성 판정 체크리스트 (스스로 검증)

- [ ] 캘린더에 records의 실제 행이 상태색 뱃지로 뜬다 (창작 데이터 0)
- [ ] 상태색·브랜드색이 §2 팔레트 밖을 벗어나지 않는다 (새 hex 0)
- [ ] 점유율 라벨이 "목표 달성률" 의미로 표기된다
- [ ] 임시(draft) 행이 화면에 없다
- [ ] 첫 화면 = PIN 게이트, `0510`으로만 진입 — 팀즈/MS 로그인·쓰기 UI가 없다
- [ ] 모든 라벨 한국어, 버튼에 이모지 없음
