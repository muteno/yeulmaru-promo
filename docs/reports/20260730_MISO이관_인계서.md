## 0. 한 줄 요약

예울마루 대시보드를 GS MISO(`gscyeulmaru.miso.gs`) 안에 **React 앱으로 다시 만들게 지시**하는 작업이다.
우리가 코드를 배포하는 게 아니라 **MISO 안의 LLM(Playmaker)에게 명세·데이터·CSS를 첨부해서 만들게** 한다.
따라서 산출물은 앱이 아니라 **「지시서 + 데이터 + 정본 CSS」 3종 패키지**이고, 전부 `이관본/`에 있다.

**지금 상태**: 데이터·명세·CSS 정본 전달 준비 완료 · MISO 빌드 1차 결과 실측 진단 완료 · 2차·3차 보강 지시 전달 대기.

## 1. 절대 잊으면 안 되는 제약 3개

| # | 제약 | 왜 중요한가 |
|---|---|---|
| 1 | **발행(publish)에 관리자 승인 + 비용이 든다.** 운영자는 MISO 관리자가 **아니다** | 재발행이 자유롭지 않다 → **한 번에 최대한 많이** 담아 보내야 한다. "일단 이거 고쳐보고 또 보자"가 안 된다 |
| 2 | **preview URL은 로그인 벽(403)** — 원격 세션이 직접 못 읽는다 | 우리가 결과를 볼 방법은 ① 운영자 스크린샷 ② 콘솔 스니펫 ③ 로컬 CDP 프로브뿐 (§5) |
| 3 | **운영자 PC가 아직 내부망에 못 붙는다** | CDP 프로브는 그때까지 못 돈다. 현재는 스크린샷 + 예측 기반으로 지시서를 만든다 |

> 운영자 원문: *"이게 발행에 비용이 드니까"* / *"재발행해도 승인을 받아야하거든? 그러니까 가능한 한번에 많은걸 수행해야해"* / *"내 pc가 저 망에 붙어야돼. 지금 문제가 있어서"*

| 항목 | 실측값 |

## 5. MISO 상태를 받아오는 3가지 경로 (발행 비용 0)

| 방법 | 절차 | 언제 |
|---|---|---|
| **① 콘솔 스니펫** (권장·즉시) | MISO preview에서 F12 → Console → `allow pasting` 엔터 → `이관본/첨부/진단스니펫.md`의 블록 붙여넣기 → 결과가 클립보드에 복사됨 → 채팅에 붙여넣기 | 지금 당장 |
| **② 스크린샷** | 운영자가 캡처해서 채팅에 첨부 | 지금 당장 · 시각 확인엔 최고 |
| **③ CDP 프로브** (가장 정확) | 크롬을 `--remote-debugging-port=9222`로 띄우고 MISO 진입 → `npm i -D playwright-core` → `node tools/miso/probe_preview_local.mjs` → 나온 md·png를 채팅에 주기 | **운영자 PC가 내부망에 붙은 뒤** |

⚠️ 세션 쿠키를 원격에 넘기는 방법은 **권장하지 않는다**(세션 토큰 노출).
