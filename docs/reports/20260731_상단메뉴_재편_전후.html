4. 그 밖에 달라진 점

  • 홍보는 캘린더 한 지붕 — 구 ‘홍보 신청·확인’ 대메뉴 폐지, 홍보 신청 + 온·오프라인 홍보 현황이 캘린더 세부로. ‘홍보 현황’이 캘린더·판매 현황 양쪽에 있던 중복 해소.
  • 회원 관리 = 대메뉴 5번 — 구 ‘사업 실적 ▸ 회원 조회’ 승격. 개인정보라 관리자에게만 대메뉴가 보임(비관리자 = 대메뉴 4개).
  • 대시보드·캘린더도 세부메뉴 생김 — 클릭 = 기존대로 화면 전환, 호버 = 세부 드롭다운(구 ‘상품 등록·변경’의 “둘다” 패턴 계승).
  • 관리 6종은 그대로 톱니(⚙) — 손대지 않음.
  • 기존 딥링크 안 깨짐 — 폐지된 해시 #prodreg→판매 현황, #promoapply→캘린더, #bizstatus→대시보드로 alias.
  • 디자인 신규 값 0 — 드롭다운 항목 문법·색·호버 알파 전부 기존 빌더 계승. check_design.py 통과(raw hex 1605/1605 동결).
