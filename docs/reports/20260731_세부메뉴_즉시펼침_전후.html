3. 무엇을 고쳤나

  • buildNav의 b.onmouseenter에서 120ms setTimeout 가드 삭제 → _ddOpen 즉시 호출.
  • 같은 메뉴 재호버는 그대로 유지(깜빡임 방지), 다른 메뉴로 옮기면 기존 모핑 전환(_ddMorph) 그대로.
  • 등장 모션은 무접촉 — 데스크탑 acctDrop .22s · 모바일 ddFold .55s 그대로. 바뀐 건 “언제 시작하나”뿐.
  • 닫힘 지연(160ms · 버튼↔메뉴 사이 갭 커버)도 그대로 — 내려가다 닫히는 일 없음.
  • 디자인 신규 값 0 · check_design.py 통과.
