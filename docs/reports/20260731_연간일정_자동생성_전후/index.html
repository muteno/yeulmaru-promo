연간 일정 타임라인 = 프로그램 시트 자동 생성 (서식 유지)

2026-07-31 · 손 마크업 25건 → 데이터 구동 · 실렌더(헤드리스 Chromium) 실측 첨부

무엇이 바뀌었나

타임라인 25건이 전부 손으로 쓴 마크업이라, 시트에 새 공연·전시를 등록해도 연간 일정엔 영영 안 들어왔다(전시 3건째를 손으로 넣은 게 직전 작업). 이제 서식은 그대로 두고 내용만 프로그램 시트에서 만든다.

프로그램 시트→ _ycItems→ _ycBuild
(마크업 조립 = 서식 1벌)→ 로그인 화면 _ycSync / 스냅샷 build_annual.mjs
(비로그인 ?annual·저장본)
  • 로그인 — 프로그램 시트(PERFS)가 도착하면 _ycSync가 타임라인을 다시 그린다. 시트에 등록하면 그날로 반영.
  • 비로그인(?annual 공유 링크·내려받은 HTML) — API를 못 부르므로 마크업의 <!-- YC-AUTO --> 스냅샷이 보인다. 스냅샷은 node tools/build_annual.mjs가 같은 _ycBuild로 다시 찍는다 → 렌더러 1벌 = 서식 드리프트 0.
  • 시트에 없는 편집 정보(유지보수 구간)만 상수로 남긴다 — _YC_MAINT = 2–3월·7–8월(현재 값 그대로).

서식은 그대로 — 값만 시트 기준으로 정정

아래 두 컷은 같은 화면이다. 도형·색·간격·좌우 배치가 한 픽셀도 안 바뀌고, 장도 전시 시작일만 시트 정본으로 정정됐다(2.27 → 3.27).

BEFORE — 손 마크업 (장도 시작 2.27, 시트와 불일치)
AFTER — 자동 생성 (장도 시작 3.27 = 시트 정본)
BEFORE — 1월 (다웃파이어 요일 오기)
AFTER — 1월 (1.24 토 · 25 일 자동 산출)
BEFORE — 10월 (10.22 공연 없음 · 상세 링크 없음)
AFTER — 10월 (10.22 신규 합류 · 링크 자동 연결)

자동 생성이 바로잡은 것 (구 손 마크업 → 시트 기준)
