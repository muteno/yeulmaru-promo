달라진 점
  • 최근 7일 추이 = 좌측 → 가운데 정렬(머리글·값 같이). 막대가 7칸 고정이라 셀 안 폭이 일정해 가운데가 흔들리지 않아.

  • 추이 ↔ 장르 사이도 +18px. 여는 쪽 셀의 왼쪽 여백만 키운 거라 열 폭(총합 100)·드래그 조절은 그대로야.
