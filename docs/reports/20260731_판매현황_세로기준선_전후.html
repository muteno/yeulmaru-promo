4. 어떻게 맞췄나

  • 공용 숫자 슬롯 _ryNumSlot() — 숫자를 고정폭(3.7em) 박스에 우측 정렬. 자릿수가 달라도 일의 자리가 같은 선에서 끝나고, 단위(%·명)와 (분자/분모)도 자동으로 같은 x에서 시작. 판매율·전시 누적 관객수가 같은 슬롯을 써서 두 표가 서로 맞음.
  • 전시 강조색 — _ryAccCell 수치 색을 var(--accent)(남색) → var(--peach-text). 전시 그룹 머리글과 같은 토큰이라 신규 색 0.
  • 차트 흔들림 — 우측 숫자 블록이 min-width:56px(가변)라 +63,000석 같은 큰 값에서 내용 폭이 커지고, 셀이 가운데 정렬이라 그만큼 막대가 밀렸다 → 고정폭으로 못박음.
  • 머리글 ↔ 막대 축 — 셀 내용은 [막대 67][간격 10][숫자 56]인데 셀 전체를 가운데 정렬해서 머리글 중심이 늘 33px 오른쪽이었다 → 머리글 td에 padding-right:76px. 식으로 풀면 열 폭과 무관하게 성립해서 드래그로 폭을 바꿔도 계속 맞는다. 열 너비 조절 손잡이(.ry-rz)는 padding box 기준이라 영향 없음.
  • 열 폭 저장 키 ryColW2 → ryColW3 — 예전에 드래그해 둔 값이 새 기본 폭을 덮어써 "안 바뀌네"가 되는 걸 막음(이후 드래그는 정상 기억).
  • 신규 색·토큰 0 · check_design.py 통과(raw hex 1605/1605 동결) · JS 에러 0.
