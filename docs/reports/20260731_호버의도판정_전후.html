2. 실측 (?qa=admin · 실제 앱에 mousemove 주입해 속도 판정 확인)

포인터 움직임측정 속도판정

경계값 _NAV_HOV_SLOW = 0.55px/ms(550px/s) — 겨냥 이동(0.18~0.37)과 통과(1.54~3.61) 사이가 넉넉히 벌어져 오판 여지가 작아.

3. 무엇을 고쳤나

  • document mousemove 1개로 포인터 속도만 기록(_navPtr · 숫자 4개). _navPtrV() = 마지막 이벤트가 70ms 넘게 없으면 멈춤(0).
  • buildNav 호버: 속도 ≤ 임계값이면 지연 0 즉시 열기(직전 작업 그대로), 초과면 보류 후 60ms 주기로 재판정 — 느려지거나 멈추면 그 순간 열림.
  • 버튼을 벗어나면 예약 취소(mouseleave + :hover 재확인) — 지나간 뒤 뒤늦게 튀어나오는 일 없음.
  • 못 열리는 메뉴는 없음 — 아무리 빨리 지나가도 그 자리에 멈추면 열려.
  • 등장 모션(acctDrop .22s) · 닫힘 지연 160ms · 모바일 아코디언 축 무접촉. 신규 CSS·색 0 · check_design.py 통과.
