① 담당자 특별일정 모달 — 유형·내용 칸

텍스트칸 2곳에만 클립 부착(빈칸 = 붙여넣기·지우개 2버튼, 복사는 내용 있을 때) · 날짜/시간 칸은 무부착 · 레이아웃 Δ0(입력칸 폭 430 유지).

② 내 할 일 메모 — 제목 칸

동적 팝오버(런타임 생성)도 MutationObserver가 자동 부착 · 시간 칸(type=time)은 무부착.

③ 챗봇 입력칸 — 플렉스 행

플렉스 행 아이템 지위 승계(래퍼가 flex 계승) — 발사 버튼 무손상.

④ 내용 입력 후 = 복사 버튼 노출

내용이 생기면 [복사 | 붙여넣기 | 지우개] 3버튼. 붙여넣기 = 캐럿 위치 삽입(덮어쓰기 아님).

⑤ 지운 직후 ~10초 = 되돌리기

지우개 클릭 = 비움 → 10초간 픽토그램이 되돌리기(↩)로 — 실측: 재클릭 시 «마케팅 세미나 공지문» 복원 확인. 붙여넣기도 동일하게 무장.

⑥ 붙여넣기 폴백(권한 차단 환경)

readText 거부 시 «길게 눌러 붙여넣기» 다이얼로그 — 정본 .u-pop 값 + .btn 컴포넌트 계승 · 평의회8 지적(좌귀퉁이 붙음) 수정 후 정중앙 실측(box x=780/1920).

⑦ 팬텀 가드 — 숨김 칸엔 클립 없음

「기타」 미선택 = 유형 직접입력 칸이 숨김 상태 — 유령 버튼 0(평의회2·8 지적 반영: 숨김 칸 부착 보류 → 노출 후 첫 포커스에 부착 실측).
동기화 생명선(화면 무변화 축) 실측: 입력 포커스 중 배포 감지 = 「작업 중이라 이월」 로그 + 리로드 0 · 한가 상태 = 「자동 리로드로 신규 코드 탑재」 + 실제 리로드 발생(Last-Modified 단조 축 — 평의회1 개정). sw.js는 HEAD를 안 가로챔(method!==GET 조기 통과) = 감지 항상 진짜 네트워크. busy 격리 실측 = 상주 숨김 z99999 3형 false·가시형 true·저장 스피너 true·쓰기 비행 중 true.
