Q39 노뮤트 에디터 기능 배선 — 전/후 실측

입력칸 클립(복사·붙여넣기·지우개/되돌리기 · 전 텍스트칸 3층 자동부착) + 동기화 생명선(복귀 재동기·새 배포 자동 탑재).
헤드리스 1920×1080 · QA 목데이터(?qa=admin) 캡처. 원본 = nomute-editor nm-clip/nm-sync · 스킨 = 이 레포 토큰 재스킨(신규 hex 0 · check_design 1605/1605 동결 유지).

① 담당자 특별일정 모달 — 유형·내용 칸

텍스트칸 2곳에만 클립 부착(빈칸 = 붙여넣기·지우개 2버튼, 복사는 내용 있을 때) · 날짜/시간 칸은 무부착 · 레이아웃 Δ0(입력칸 폭 430 유지).

② 내 할 일 메모 — 제목 칸

동적 팝오버(런타임 생성)도 MutationObserver가 자동 부착 · 시간 칸(type=time)은 무부착.

③ 챗봇 입력칸 — 플렉스 행

플렉스 행 아이템 지위 승계(래퍼가 flex 계승) — 발사 버튼 무손상.

④ 내용 입력 후 = 복사 버튼 노출

내용이 생기면 [복사 | 붙여넣기 | 지우개] 3버튼. 붙여넣기 = 캐럿 위치 삽입(덮어쓰기 아님).

⑤ 지운 직후 ~10초 = 되돌리기

지우개 클릭 = 비움 → 10초간 픽토그램이 되돌리기(↩)로 — 실측: 재클릭 시 «마케팅 세미나 공지문» 복원 확인. 붙여넣기도 동일하게 무장.

⑥ 붙여넣기 폴백(권한 차단 환경)

readText 거부 시 «길게 눌러 붙여넣기» 다이얼로그 — 정본 .u-pop 값 + .btn 컴포넌트 계승.
동기화 생명선(화면 무변화 축) 실측: 입력 포커스 중 배포 감지 = 「작업 중이라 이월」 로그 + 리로드 0 · 한가 상태 = 「자동 리로드로 신규 코드 탑재」 + 실제 리로드 발생. sw.js는 HEAD를 안 가로챔(method!==GET 조기 통과) = 감지 항상 진짜 네트워크.
