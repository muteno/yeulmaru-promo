4. 어떻게 그렸나 — 막대는 테두리에 점선을 못 준다

  • Plotly bar의 marker.line은 dash를 지원하지 않는다. → 같은 자리에 layout.shapes 사각(line.dash:'dot')을 얹어 「빈 기둥」을 만들었다. 기존 dash:'dot' 문법(근4개년 추이선·레일 예측선) 계승 · 신규 색 0.
  • 기둥 = 2단: 아래 y 0 → 실적(기존 막대, 면 알파 .14) / 위 y 실적 → 예상(점선 테두리, 면 알파 .07 = 「아직 안 채워짐」).
  • 2026 기둥 폭 = 다른 해의 1.5배(막대 width 배열 0.4 → 0.6 · 실측 20.7px → 31.0px). 넓힌 칸의 오른쪽 여백 = 「예상 6.1」 값 라벨 자리.
  • shape은 hover를 못 받으므로 기둥 꼭대기에 투명 히트존 1점을 얹어 산식이 툴팁으로 뜨게 했다.
