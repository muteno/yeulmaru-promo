무엇이 문제였나 (전)

전 — 100% (1920×1080): 기준 화면. 차트가 fit 로직으로 383px까지 줄어 딱 맞음
전 — 80% 상당 (2400×1350): 차트 상한 560px 정지 + 보드 아래 죽은 여백 163px · 구도 붕괴

핵심 역전: 물리 픽셀로 차트가 80%에서 448px > 100%에서 383px — "확대(80→100%)하면 오히려 작아지는" 현상의 실체. 고정 px 규격(폰트·표 높이)과 뷰포트 비례 컨테이너(50% 폭)가 섞여 배율마다 구도가 달라졌다.

무엇을 했나

대시보드(biz 모드·레일 표시 폭)에서 #body-wrap에 CSS zoom = 뷰포트폭 ÷ 1920(클램프 .75~2.2)을 걸어 항상 1920 기준 디자인 공간에서 레이아웃하게 함(_bizZoomApply). 100% 화면 = z1 → 종전과 완전 동일(무변). 좌표계 실측(Chrome 141) 기반 보정 3종: ① gBCR(시각좌표)로 잰 값을 style px에 쓰는 정렬식 전부 _bizZ() 나눗셈(_bizFitViewport·_srailAlignTop biz 분기·행 하이라이트) ② min-height:calc(100vh−56px)는 zoom에 이중 스케일 → px 보정 ③ Plotly 포인터 좌표 줌 보정 심(_bizPlotlyZoomShim — z1.25에서 2019 지점 호버가 「2021년」으로 어긋나던 것 실측·수정).
