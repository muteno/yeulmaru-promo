입력 기능, 대시보드 안으로

판매 현황 메뉴의 남은 두 입력구 — 실적 입력(admin)·상품 등록·변경 — 를 대시보드 「프로그램 별 판매 추이」에 편입하는 4안. 모달 자체는 기존 것(openDailyInput·openTicketReg) 재사용 = 진입구만 옮긴다. 부품 = 정본(.pm-fbtn·.ana-chip·.ry-spec-edit 문법)·신규 색 0.

① 배치 프리셋

② 헤더 버튼 (A안 축)

③ 행 연필 (B안 축)

④ 상세 카드 버튼 (C안 축)

⑤ 메뉴 정리

제거는 입력 편입 구현과 같은 커밋에서 — 그 전에 지우면 실적 입력·상품 등록이 갈 곳이 없다. 실적 조회 몫은 이미 대시보드 표(판매중만 토글)가 흡수.

⑤′ 재현 한계 각주

      · 모달 본체(openDailyInput 폼·배치 업로드)는 재현 생략 — 클릭 = 토스트로 「무엇이 열리는지」만 시뮬(모달은 기존 그대로 재사용이 전제).

      · 배경 항공사진·좌측 연간 실적 열·2×2 자동전환 모션은 생략(우측 열 발췌 재현). 표 데이터 = 목값.
