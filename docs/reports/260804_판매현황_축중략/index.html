안 끊는 예(실측) — 같은 화면 「명(판매 고객)」 모드: 3,332 / 1,761 / 1,000 / 918 / … 은 2배 점프가 없어 중략 미발동(shape 0개 · 눈금 자동) = 고른 분포는 현행 그대로 그린다.
