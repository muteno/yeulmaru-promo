  • 좁은 화면(≤1200, 한 열) = 같은 순서 유지(KPI → 판매현황 → 축적 → 표).

폐기한 시안 — 축적 카드 세로 flex(게이지 가운데 정렬)

큰 화면에서 카드가 늘어날 때 생기는 아래 여백을 위·아래로 나누려 했으나, flex 아이템은 max-height가 걸리면 줄어든다. 그러면 _srailAlignTop의 넘침 흡수 판정(scrollHeight > 안선−자기상단)이 「걸면 안 넘침 → 해제 → 다시 넘침」으로 진동해 멱등이 깨진다 — 1440×820 실측 = 좌 흰 도형이 안선 아래 53.1px(스모크 FAIL). 블록 레이아웃 유지로 되돌렸다.
