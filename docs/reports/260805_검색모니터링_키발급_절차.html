「예울마루」 검색 모니터링 — 키 발급 절차

네이버 플레이스 공연·전시 탭을 직접 읽는 공개 API는 없다. 대신 ① 구글은 Google Alerts RSS(키 불필요) ② 네이버는 검색 오픈 API(무료·25,000회/일) ③ 그 탭의 원천인 공연 목록은 KOPIS OpenAPI(무료)로 가져온다. 아래 순서대로 하면 된다.

Google Alerts — 구글 검색 모니터링

google.com/alerts 무료 · 키 불필요 3분

Google Alerts 열기 — 구글 로그인 상태로

  1. 상단 검색창에 예울마루 입력
  2. 옵션 표시 클릭
  3. 수신 위치(Deliver to) → RSS 피드 선택 ← 핵심. 기본값은 이메일이라 반드시 바꿔야 한다
  4. 수신 빈도 수시로 · 소스 자동 · 언어 한국어 · 지역 대한민국 · 개수 모든 결과
  5. 알림 만들기 클릭
  6. 목록에 생긴 알림 오른쪽 RSS 아이콘을 우클릭 → 링크 주소 복사

복사한 주소 생김새 (숫자는 계정마다 다름)

https://www.google.com/alerts/feeds/12345678901234567890/9876543210987654321

키워드를 더 만들 거면 (각각 RSS 주소가 따로 나온다)

GS칼텍스 예울마루
예울마루 공연
예울마루 전시
ⓘ 구글 공식 Custom Search JSON API는 신규 가입이 막혔고(공식 문구 “closed to new customers”) 기존 고객도 2027-01-01 종료다. 그래서 새로 시작하는 우리는 이 Alerts RSS 경로가 정답이다.
누르면 진행률에 반영된다 (이 브라우저에 저장)

네이버 커버 — 검색 API 대신 site: 알림

google.com/alerts 무료 · 키 불필요 3분
⛔ 260806 실측 — 이 경로는 막혔다. 네이버 개발자센터 애플리케이션 등록 ▸ 「사용 API」 목록이 가나다순(네이버 로그인 → 네이버 인증서 → 네이버 전자문서 → 네이버페이 배송지 정보 → 카페 → 캘린더 → 캡차×2) **8종뿐**이고, ㄱ 자리에 있어야 할 「검색」이 없다(데이터랩도 없다). = 검색 API를 새로 신청할 수 없다.
운영자 화면 직접 확인이 근거다. 공식 종료 공지는 못 찾았다(미확인) — 기존 발급분이 계속 도는지도 확인 안 됨.

→ 대신 STEP 1의 Google Alerts에 site:를 붙여 네이버를 덮는다. 키가 필요 없고 지금 바로 된다. 아래 3개를 STEP 1과 똑같은 방법(옵션 표시 → 수신 위치 RSS 피드)으로 추가하면 된다.

site:blog.naver.com 예울마루
site:cafe.naver.com 예울마루
site:post.naver.com 예울마루
⚠ 한계를 분명히 한다 — 이건 구글이 색인한 네이버 문서만 잡는다. 네이버 자체 검색결과와 1:1로 같지 않고, 특히 카페 비공개 글·최신 글 반영은 늦거나 빠진다. 네이버를 온전히 덮으려면 검색 API가 필요한데 그 문이 닫혔다 — 이 우회로가 현재 최선이다.
ⓘ 서버 코드는 네이버 API 갈래를 그대로 남겨뒀다(NAVER_SEARCH_ID/SECRET). 나중에 키를 얻게 되면 Cloudflare에 넣는 순간 코드 수정 없이 그 갈래가 켜진다.
site: 알림 3개를 추가했으면 켠다

공공데이터포털 — KOPIS 공연목록 (= 플레이스 탭의 원천)

data.go.kr 무료 · 자동승인 🔒 시크릿 5분

KOPIS 공연목록 API 열기 — 회원가입 필요

  1. 회원가입 / 로그인 (일반회원)
  2. 우측 상단 활용신청 클릭
  3. 활용목적 기타 → 사유에 아래 문구 붙여넣기
  4. 라이선스 동의 체크 → 활용신청
  5. 개발계정 = 자동승인이라 즉시 발급된다
  6. 마이페이지 → 데이터활용 → Open API → 인증키 발급현황
  7. 일반 인증키(Encoding) 값 복사

활용 사유 (그대로 써도 된다)

기관(GS칼텍스 예울마루) 공연정보의 자체 홈페이지 게시 및 내부 모니터링

호출 형태 — 참고용. 실제 배선은 내가 한다

http://kopis.or.kr/openApi/restful/pblprfr?service=<키>&stdate=20260801&eddate=20261231&cpage=1&rows=100
⚠ KOPIS는 공연만 — 스크린샷의 전시 탭은 이걸로 안 나온다. 또 예매 최초 결제 다음날에 데이터가 넘어오므로, 막 등록된 「공연예정」은 잠시 비어 있을 수 있다. 전시가 급하지 않으면 STEP 3은 건너뛰고 1·2만 먼저 해도 된다.
미확인 1건 — 「공연시설명으로 직접 거르는 파라미터명」은 발급 시 함께 받는 공통코드 PDF 명세서에서 확인해야 한다. 안 되면 목록을 받아 예울마루로 걸러내면 되니 결과는 같다.
건너뛸 거면 안 켜도 된다

Cloudflare — Worker에 시크릿 등록

dash.cloudflare.com yeulmaru-promo-api 2분

Cloudflare 대시보드 열기

  1. Workers & Pages → yeulmaru-promo-api 클릭
  2. Settings → Variables and Secrets
  3. + Add → Type = Secret → 아래 3개를 하나씩 추가
  4. 저장 / Deploy

시크릿 이름 — 철자 그대로여야 코드가 찾는다

이름값
GALERT_RSSSTEP 1·2의 RSS 주소 전부 한 값에 — 줄바꿈·쉼표·공백 아무거나로 이어 붙이면 된다(최대 12개)
KOPIS_KEYSTEP 3의 일반 인증키(Encoding)
NAVER_SEARCH_ID
NAVER_SEARCH_SECRET		보류 — 검색 API 신규 발급이 막혔다(STEP 2). 언젠가 키가 생기면 넣는 즉시 그 갈래가 켜진다
⚠ RSS 주소는 비밀번호는 아니지만 운영자 구글 계정 ID가 들어 있다 — 이 레포는 Public이라 코드·문서에 안 싣고 여기(Cloudflare 변수)로만 넣는다.
ⓘ 나중에 값이 바뀌면 이 화면에서 덮어쓰기만 하면 되고 코드는 안 건드린다. KEYS.md의 GEMINI_API_KEY·KASI_KEY가 사는 곳과 같은 자리다.
3개 다 넣고 배포까지
