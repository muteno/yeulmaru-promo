장도 입도 시간 — 글 안에서 바로 보이게 (260805-2)

홈페이지 저장 필터가 iframe을 삭제하는 게 실측으로 확인됐다(저장 후 본문에 태그·도메인 문자열 0). 살아남는 <img>를 쓴다 — 서버(Worker)가 오늘 시간을 이미지(SVG)로 그려서 내주면 스크립트 없이 글 안에서 바로 보인다. 아래 「후」의 카드는 실제 생성 결과다.

전 — 지금(버튼 링크)

오늘 장도 입도 가능 시간 바로 확인 →
월별 캘린더 이미지 ×5
시간을 보려면 새 창을 한 번 거쳐야 한다. 글만 봐서는 오늘 몇 시까지인지 알 수 없음.

동작 방식

  • 홈페이지 서버에는 아무것도 설치하지 않는다 — 본문에 이미지 한 줄만 들어간다(유튜브 썸네일 넣는 것과 같은 수준).
  • 이미지는 볼 때마다 Worker가 그 시점 기준으로 새로 그린다 — 시트에 시간이 갱신되면 글은 손대지 않아도 따라온다.
  • 시각 = 한국시간 고정(방문자 기기 시간대와 무관) · 캐시 2분(「지금 입도 가능」 문구가 최대 2분까지만 낡음).
  • Worker 장애 시에도 깨진 이미지 아이콘 대신 안내 문구를 그린 카드가 나온다(④ 형태).
