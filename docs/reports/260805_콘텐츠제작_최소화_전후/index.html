3. 동작 계약 — 「숨김」이지 「닫기」가 아니다

  • 최소화 = display:none — DOM·타이머·업로드가 그대로 살아, 한글·오피스·용량 줄이기의 러너 작업이 뒤에서 계속 돈다(긴 작업 중 다른 화면 보기 = 이 버튼의 핵심 용도).
  • 복원 = 독 칩 클릭 또는 메뉴 재진입 — 「매번 새로」 리셋 도구(카드·카카오·블로그·한글·오피스…)도 최소화 중 재진입이면 리셋 대신 복원(작업 보존). 복원 보드는 열려 있는 다른 보드 위로 z 부양.
  • Esc 가드 — 최소화 중 Esc는 숨은 보드를 건드리지 않는다(도화지는 Delete·undo 등 문서 키 전부 무시). 다른 모달의 Esc 동작은 그대로.
  • 스크롤락 — 도화지·에니어그램 최소화 = body 스크롤 복구, 복원 = 재잠금(닫기 함수들의 상호 검사와 같은 축).
  • 부품 전부 정본 계승 — 버튼 = .modal-x/.bp-x에 글자 ─(X 정본 게이트⑦의 X_FAMILY 밖 = 별개 버튼으로 판정) · 칩 = .bp-tbtn · 독 z = --z-toast(고아 토큰 재활성). 신규 색·클래스·raw hex 0.
새로고침·로그아웃은 여전히 초기화. 최소화는 페이지 수명 안의 보관이다 — 공용 PC에서 화면을 떠나면 소멸한다는 각 도구의 프라이버시 계약(「매번 새로」)은 그대로 유효하다.
