양면 동시 로딩 = 펼침 기준 빗살 — 전후

운영자 지시 260806-14 「양면이 로딩중일 때는 모든 양면을 기준해서 빗살이 쓸어가게」 · 앞 단계(260806-12 = 빗살을 카드 한 장 전면으로) 위에 얹는 후속 · 화면 = ?qa=admin 목데이터 · 1920×1080 · 좌 = 3면 「사업 결과 비교」(운영 데이터 미도착) · 우 = 「판매 실적」(판매중 목록 미도착) · 스윕 위상 translateX(60%) 고정 컷.

1. 전후 — 띠가 둘이냐, 하나냐

전 — 카드마다 자기 띠(둘이 나란히 지나간다)
후 — 펼침 하나를 가로지르는 띠 하나
전은 두 카드가 각자 34% 폭의 띠를 각자 같은 상대 위치로 굴린다 → 같은 순간에 좌·우에 띠가 하나씩, 둘이 나란히 간다. 후는 좌 카드 왼끝~우 카드 오른끝을 한 좌표계로 삼아 띠 하나가 지나간다(칸 사이 빈 곳은 유리가 없어 안 보일 뿐 같은 여정).

2. 방법 — 띠의 좌표계를 카드 → 펼침으로 옮긴다

네 칸(좌·우 카드 × 머리줄·유리박스)은 각자 backdrop-filter라 서로의 영역을 넘지 못한다(260806-12와 같은 제약). 그래서 같은 띠를 네 칸에 심고, 각 칸은 그 띠의 자기 구간만 보여주는 창이 된다.
