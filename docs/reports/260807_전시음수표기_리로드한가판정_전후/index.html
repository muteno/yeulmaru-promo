전시 음수 표기 가드 + 자동 리로드 한가 판정 보강 (260807-17)

운영자 지시: 「45초 폴링 자동 리로드 그거 붙여줘 / 전시 -242 뜨는데 그러면안돼」
실측 = QA 목데이터(?qa=admin · 실API 미접촉) · 요약 블록은 배포 파일 원문 추출 실구동 · 자동 리로드는 배포 감지~리로드 전 구간 실연.

① 헤더 요약 「전일 대비」 — 전시 음수(누계 하향 보정) 표기 생략

원인 = 입력 흐름이 일일총인원을 누계 차분으로 파생 저장 → 누계를 내려 잡는 보정일에 음수가 시트에 남는다. 관객 발길은 음수일 수 없으므로 요약 증감에서 음수 제외(v>=0 가드 · 값 자체는 시트·상세 그대로). 7일 막대는 종전부터 음수를 0으로 클램프해 무접촉.

② 45초 자동 리로드 — 한가 판정을 Q39 정본 busy()로 보강

자동 반영 축 자체는 260806-8에 배선 완료(45초 틱 → 배포 감지 → 한가하면 reload). 이번 보강 = _designSafeNow에 nmSync.busy() 합류 — 구판은 비행 중 쓰기(_apiWrites)·MSAL·AI 응답·저장 스피너·z99999 오버레이를 못 봐 저장 절단 창이 남아 있었다(실측: 전 = 쓰기 중에도 즉시 리로드 · 후 = 보류→배지→쓰기 끝나면 다음 판정에서 자동 탑재). 기존 검사(SELECT 포커스·프로모 마법사)는 busy()에 없는 몫이라 합집합 유지.
