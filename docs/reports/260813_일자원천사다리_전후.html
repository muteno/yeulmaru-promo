일자 원천 사다리 — 「데이터 없음」 + 도착하면 자동으로 채워짐

260813 · 운영자 「데이터를 가능한 끌어와보고 안 되는 건 데이터 없음으로 채우고 · 공연 기준으로 틀을 만들어 놓고 추후 데이터를 가져왔을 때 배선하기 쉽게」. pageerror 전/후 0 / 0.

①원천을 표 한 곳에 세운다 — 늘릴 땐 한 칸만 더한다

사업비 원장엔 날짜 칸이 없다. 「이 사업이 어느 프로그램인가」를 이미 세워 둔 연결(_finOf)로 물어 그쪽 일자를 가져온다. 원천 목록은 이 표 하나고, 소비처(분야별 표·사업별 매출 차트)는 _finDateOf만 부른다.

var _FIN_DATE_SRC=[
  {k:'공연', rows:function(year){ …운영대장 등록 공연… }},
  {k:'전시', rows:function(year){ return _bizExhibRows(year); }},
  {k:'교육', rows:function(year){ return _bizEduMonthRows(year); }}
];   // ← 새 원천은 여기 한 칸. {name, start, end} 셋만 맞추면 붙는다.

위에서부터 먼저 답하는 원천이 이긴다. 목록이 null이면 「아직 안 왔다」지 「없다」가 아니다 — 그 사업은 다음 칸(진행월)으로 내려가고, 데이터가 도착하면 그 면이 다시 그려진다.

②못 찾은 일자 = 빈칸이 아니라 「데이터 없음」
