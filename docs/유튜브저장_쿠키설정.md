# 유튜브 영상 저장이 막힐 때 — 쿠키 1회 설정 (운영자용)

## 무슨 일이 있었나 (260803 실측)

링크 자료수집에서 유튜브 [저장]을 누르면 변환이 실패한다. 화면에 뜨던
「초대형(6GB 초과) 여부를 확인해 주세요」는 **틀린 안내**였다(그 문구는 원인과 무관하게 항상 떴다).

진짜 원인은 이것이다:

```
ERROR: [youtube] Sign in to confirm you're not a bot.
```

**유튜브가 GitHub Actions 러너의 IP를 봇으로 보고 막는다.** 영상 문제가 아니다 —
실측으로 확인했다:

| 대상 | 결과 |
|---|---|
| ILLIT ‘It's Me’ MV | 봇 차단 |
| 빅벅버니(Creative Commons, 저작권 자유) | **똑같이 봇 차단** |

즉 **어떤 영상이든 막힌다.** 클라이언트 5종(기본·web_safari·mweb·tv_simply·android_vr)을
차례로 시도하도록 고쳤고, JS 런타임(deno)과 PO 토큰 공급자도 붙였지만 그것만으로는 안 뚫렸다.
다시 눌러도 결과는 같다(일시적 장애가 아니다).

## 푸는 방법 — 쿠키 1회 등록 (5분, 한 번만)

유튜브에 **로그인한 상태의 쿠키**를 리포 시크릿에 넣어두면 러너가 「사람의 브라우저」로 인정받는다.
이미 워크플로에 배선돼 있어서, 시크릿만 채우면 그 다음부터 자동으로 쓰인다.

### 1. 쿠키 파일 뽑기

1. 크롬/엣지에 확장 **「Get cookies.txt LOCALLY」** 설치
   (웹스토어 검색 → 설치. *LOCALLY* 붙은 것으로 — 서버로 안 보내는 판이다)
2. **시크릿 창**을 열어 youtube.com 에 로그인
   → 시크릿 창을 쓰는 이유: 평소 쓰는 창에서 뽑으면 나중에 그 창에서 로그아웃할 때 쿠키가 같이 죽는다.
3. 그 탭에서 확장 아이콘 클릭 → **Export** → `cookies.txt` 저장
4. **그 시크릿 창은 닫지 말고 그대로 둔다**(닫으면 세션이 끝나 쿠키가 무효가 된다)

### 2. 리포 시크릿에 넣기

1. https://github.com/muteno/yeulmaru-promo/settings/secrets/actions 접속
2. **New repository secret**
3. Name: `YT_COOKIES`
4. Secret: `cookies.txt` 파일을 **메모장으로 열어 전체 복사 → 붙여넣기**
5. **Add secret**

### 3. 확인

앱에서 유튜브 주소를 넣고 [저장]을 눌러보면 된다.
(또는 Actions 탭 → 「링크 자료수집 영상 저장」 → Run workflow → 주소 입력)

## 주의

- 쿠키 = **로그인 자격**이다. 시크릿에 넣으면 GitHub이 암호화해 보관하고 로그에도 안 찍히지만,
  그래도 **주 계정 말고 별도 유튜브 계정**을 쓰는 걸 권한다.
- 쿠키는 몇 주~몇 달 뒤 만료된다. 다시 봇 차단 문구가 뜨면 위 1~2를 다시 하면 된다.
- 쿠키를 빼려면 그냥 시크릿을 삭제하면 된다 — 워크플로는 시크릿이 없어도 그대로 돈다(없으면 종전처럼 시도만 한다).

## 참고 — 실패 사유는 이제 화면에 그대로 뜬다

앱이 러너의 실제 에러를 읽어 사람 말로 옮긴다(봇 차단 · DRM · 연령 제한 · 비공개/삭제 ·
용량 상한 · 없는 화질 · 진행 중 라이브). 모르는 사유는 지어내지 않고 원문 앞부분을 그대로 보여준다.
실패한 변환의 `err.txt`에는 진단 줄(JS 런타임·PO 토큰 공급자가 실제로 켜졌는지)도 함께 실린다.
