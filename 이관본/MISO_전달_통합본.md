## 1. 임무 요약

GS칼텍스 예울마루(여수 문화예술공원)의 **사업·홍보 조회 대시보드**를 만든다.

- **진입 = PIN 게이트 한 장.** 첫 화면에 "예울마루" 타이틀 + 4칸 PIN 입력. **`0510`** 입력 시 통과. 그 외엔 흔들림 + 빨강 안내("PIN이 올바르지 않습니다"). **팀즈/Microsoft 로그인·계정 선택·비밀번호 단계는 절대 만들지 마라.**
- **데이터 = 이 문서에 든 것 + 첨부 CSV가 전부.** 창작·추정 금지. 없으면 "데이터 없음" 표기.
- **쓰기(등록·수정·삭제) 없음.** 조회·검색·필터만.
- 모든 UI 텍스트 **한국어**.

## 3. 화면 (상단 내비 1줄 "예울마루" + 메뉴 4개)

### ① 홍보 캘린더 (기본 화면)
- 월간 그리드. `records`의 각 행을 `날짜`(또는 `연도`·`월`·`일`)별 뱃지로.
- 뱃지 텍스트 = `콘텐츠 제목`(없으면 `프로그램`). 뱃지 색 = `진행 상태`: 완료 `#1A6B3C` / 취소·반려 `#E24B4A` / 신청 중·보류 `#D88455` / 예정·승인 `#4A4DE7` (연한 배경 + 진한 글자).
- `special`(특별일정: 교육·휴가·출장·회의)는 회색 뱃지로 병기. 뱃지 클릭 → 상세 모달. 오늘 셀 강조. 월 이동 ‹ ›.

### ② 프로그램
- `programs` 카드: `풀네임`, 기간(`시작일`~`종료일`), `장소`, `담당자`, `콘텐츠구분`. 판매중(오늘이 `판매시작일`~`판매종료일`) 배지. `콘텐츠구분` 필터 칩.

### ③ 사업 실적
- 공연: `ops_공연마스터`(사업·목표점유율·상태) + 첨부 `ops_일일입력`(일일 판매, `공연ID`로 조인) → 일일 추이 라인차트 + 누계 KPI.
- 전시: `exhib_master`(전시·목표·최종실적).
- ⚠️ **점유율 = 목표 달성률**(100% 초과 가능). "좌석 점유율" 아님. 차트 색 = 카테고리 6색.

### ④ (선택) 프로그램/전시 상세 모달 — 행 클릭 시 주요 필드 표.

## 4. 데이터 해석 규칙 (함정 — 반드시 지켜라)

1. **신청자 ≠ 게시 담당자**: `records`의 `신청자`가 신청 본인. "누가 신청"은 전부 `신청자` 기준(`게시 담당자`는 지정값이라 표시 주체로 쓰지 마라).
2. **엑셀 시리얼 날짜**: 일부 날짜가 46000대 정수로 있다 → `(값-25569)*86400*1000` = UTC ms. 문자열(`YYYY-MM-DD…`)은 그대로.
3. `records.진행 상태` 값: 신청 중·예정(승인)·완료·보류·취소·반려·**임시**(임시저장 — **화면에 표시하지 마라**).
4. 홍보 노출 = `programs.홍보시작일`~`판매종료일`(비면 `종료일`). "홍보종료일" 개념 없음.
5. 빈 문자열 = 값 없음. 전부 빈 행은 무시.
