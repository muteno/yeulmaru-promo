## ⭐ 최우선 경로 — 파일 1개 첨부로 끝

**standalone.html (3.85MB / 4,034,423 bytes · 26,236줄)** = 원본 대시보드 통짜 이식판.
MISO 대화형(Opus 4.8)에 첨부하고 **아래 블록을 통째로**(한 글자도 줄이지 말고) 복사해 채팅에 넣는다.

> **주의 1.** 이 파일은 읽는 문서가 아니라 배포하는 실행물이다(약 1.1M+ 토큰 — 어떤 모델 컨텍스트에도 안 들어간다). 아래 문안은 수신 LLM에게 '읽지 말고 호스팅만 하라'를 명시하도록 설계됐다.
> **주의 2. `빌드명세.md`를 같이 첨부하지 마라.** 둘 다 있으면 수신 LLM은 더 쉬운 쪽(명세대로 재구현)을 골라 이식을 망친다. 빌드명세는 이 경로가 완전히 막힌 뒤 **새 대화에서만** 쓴다.

```
[역할] 너는 지금 코드 작성자가 아니라 정적 파일 호스팅 담당이다.

[대상] 첨부한 standalone.html은 이미 완성·검증된 단일 파일 웹앱이다.
- 3.85MB / 26,236줄 / 업무 데이터가 파일 안에 내장돼 있다.
- 외부 빌드·패키지 설치·서버 코드가 전혀 필요 없다. 브라우저가 열면 그대로 돈다.
- 사내 문화시설(GS칼텍스 예울마루) 임직원 조회용이며 사내망에서만 쓴다.

[해야 할 일 — 이것 하나뿐]
이 파일을 그대로 정적 호스팅하고 접속 URL을 알려줘.

[하지 말 것 — 하나라도 하면 실패로 간주한다]
1. 파일 내용을 읽거나 요약·분석하려 하지 마라. 통째로 읽으면 컨텍스트가 초과된다. 열지 않아도 배포할 수 있다.
2. React·Next·Vue 등 어떤 프레임워크로도 변환하지 마라. 컴포넌트로 쪼개지 마라.
3. 지식베이스·데이터셋·참고자료로 취급하지 마라. 이건 실행되는 앱이다.
4. 코드를 고치거나 개선·리팩터링·최적화·압축하지 마라. 한 글자도 바꾸지 마라.
5. 비슷한 앱을 새로 만들지 마라. 재구현은 요구사항이 아니다.

[미리 답하는 질문]
- 파일 안의 4자리 숫자 상수 = 사내망 접근 게이트(계정 비밀번호 아님).
  Microsoft 인증 경로 = 이 빌드에서 코드로 봉인돼 실행되지 않음. 개인정보(연락처·이메일)는 생성 단계에서 제거됨.
- 용량이 큰 이유는 데이터가 내장돼서다. 분할하지 말고 그대로 올려라.

[성공 판정]
배포된 URL 첫 화면에 '예울마루' 타이틀 + 4칸 PIN 입력이 뜨면 성공. 그 외 화면은 실패다. URL만 주면 내가 확인한다.
```

### 알려진 한계 (정직)

- **사업 현황 보드의 대형 차트 1종은 plotly CDN 의존** — 사내망이 `cdn.plot.ly`를 막으면 그 차트만 백지(데이터·표·캘린더·메인 대시보드는 정상). 대시보드 첫 화면 차트는 내장 SVG라 오프라인에도 뜬다.
- 팀즈/MS Graph 의존 기능(OneDrive 폴더 탐색 등)은 후순위 분리 — 동작 안 함.
- **이 파일은 업무 데이터를 평문 내장한다** → 공개 URL로 서빙하면 소스보기로 열람 가능. **사내망 전용으로만 배포**하고 공개 호스팅 금지(§보안 판단, 하단).

## 갱신 규약 (기계산출물 — 손편집 금지)

- 데이터: 새 CSV를 `data/db_export/`나 레포 루트에 넣고 `npm run build:misodb`
- 이식판: `node tools/miso/build_standalone.mjs` (원본 index.html 변경도 이 명령으로 반영)
- 회원 패키지: `node tools/miso/build_members.mjs` → `비공개/` (커밋 안 됨)
- 검증: `node tools/miso/smoke_standalone.mjs` (격리 서빙 자동 · playwright 필요)
- **이 폴더 파일을 손으로 고치지 말 것** — 원본(index.html·CSV·문서 원문)을 고치고 재생성.

## ⚠️ 운영자 판단 필요 (평의회 지적 — 코드로 못 정하는 사안)

1. **공개 레포 이력의 개인정보**: main 커밋 `235857d`에 원본 xlsm(PIN·비번 평문)·회원 xlsx(29,752명 PII)가 남아 지금 공개 URL에서 다운로드된다. 삭제 커밋만으론 이력에 남음 → 이력 스크럽(filter-repo/BFG) 또는 레포 Private 전환 필요.
2. **standalone 공개 서빙 여부**: 데이터 평문 내장 → 사내망 전용 배포만. 공개 Pages(`promo.yeulmaru.org/이관본/`)를 전달 매개로 쓰는 설계는 재검토 대상.
3. **Worker 쓰기 노출**: `ALLOWED_ORIGIN=*` + 0510 공개로 실 SharePoint에 무인증 쓰기 가능 — 이식 기간 CORS 축소·0510 로테이션·쓰기 라우트 admin 승격 권장(라이브 Worker 변경이라 운영자 승인 후).
