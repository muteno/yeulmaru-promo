# 첨부 세트 + 붙여넣을 지시문 (MISO 빌더 2차)

**이 폴더의 CSV 10개를 전부 첨부**하고, 아래 지시문을 채팅에 붙여넣는다.
(통합본 `MISO_전달_통합본.md`을 이미 줬다면 그 인라인 데이터는 **요약본**이므로 이 CSV로 교체해야 한다.)

---

## 붙여넣을 지시문 (이 아래 전체를 복사)

```
[데이터 정본 교체 — 중요]
방금 첨부한 CSV 10개가 데이터 정본이다. 앞서 명세 문서 안에 인라인으로 들어 있던
요약 데이터는 폐기하고, 전부 이 CSV 파일에서 읽어 src/data/ 모듈로 다시 생성해라.
(요약본에는 records 137행 전체와 일일판매 1477행이 빠져 있었고, 전시 13행·특별일정 6행이
누락됐고, 프로그램 URL 17건이 비어 있었다. 첨부 CSV에는 전부 들어 있다.)

파일 목록과 용도:
- 01_records_홍보신청내역_137행.csv  → 홍보 캘린더의 원본. 이게 없으면 캘린더가 빈다.
- 02_programs_프로그램_30행.csv      → 프로그램 화면 (URL 열 포함)
- 03_special_특별일정_34행.csv       → 캘린더 회색 뱃지 (교육·휴가·출장·회의)
- 04_공연마스터_9행.csv              → 사업 실적(공연) 마스터, ID 열로 조인
- 05_공연일일판매_1477행.csv         → 사업 실적(공연) 일일 추이, 공연ID 열로 조인
- 06_전시마스터_25행.csv             → 사업 실적(전시) 마스터, 전시ID 열
- 07_전시일일_11행.csv               → 사업 실적(전시) 일일, 전시ID 열로 조인
- 08_platforms_10행.csv / 09_contents_5행.csv / 10_applysettings_6행.csv → 라벨·필터·설정

[⚠️ CSV 파싱 필수 주의 — 이거 틀리면 데이터가 깨진다]
1. 01_records 파일은 137행인데 파일은 1,634줄이다. "콘텐츠 내용" 열에 여러 줄짜리
   텍스트가 인용부호("...") 안에 들어 있기 때문이다(137행 중 103행이 해당).
   → 줄 단위로 split 하지 마라. 인용부호와 이스케이프("")를 처리하는 정식 CSV 파서를
     쓰거나, 파싱한 결과 행 수가 137인지 반드시 확인해라. 137이 아니면 파서가 틀린 것이다.
2. 모든 CSV는 UTF-8 BOM(﻿)으로 시작한다. 첫 헤더 이름 앞의 BOM을 제거해라
   (안 하면 첫 열 이름이 "﻿No"가 되어 조회가 실패한다).
3. 날짜는 두 형식이 섞여 있다: "2026-05-23 00:00:00" 문자열과 46023 같은 엑셀 시리얼 정수.
   시리얼이면 (값-25569)*86400*1000 = UTC ms로 변환해라.
4. 빈 문자열 = 값 없음. 전부 빈 행은 무시.

[검증 — 완성 전 이 숫자가 나오는지 확인]
- records 파싱 결과 = 137행 (진행 상태 분포: 완료 89 · 취소 31 · 예정 12 · 보류 5)
- programs = 30행, special = 34행, 공연마스터 = 9행, 일일판매 = 1477행,
  전시마스터 = 25행, 전시일일 = 11행
- 캘린더에 2026년 5~7월 뱃지가 실제로 표시되는지 (records 날짜가 이 구간에 몰려 있다)
- 임시(draft) 상태 행은 0건이므로 필터해도 화면 변화 없음이 정상

[상기 — 지켜야 할 것]
- 첫 화면 = PIN 4칸, 0510만 통과. 팀즈/Microsoft 로그인 절대 만들지 마라.
- 색은 앞서 준 팔레트만 사용(인디고 #4A4DE7 / 살몬 #D88455 / 완료 #1A6B3C / 위험 #E24B4A).
- 점유율 = 목표 달성률(100% 초과 가능), "좌석 점유율" 아님.
- 쓰기(등록·수정·삭제) 기능은 만들지 마라. 조회·검색·필터만.
```
