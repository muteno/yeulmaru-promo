## 1. ⚠ 고치기 전에 이것부터 측정해라 (빌드 없음 · 크레딧 0)

**v5 빌드 로그는 "인디고 점 + 투명 컨테이너"라고 자체 검증에 통과했다고 적었지만, 실제 화면에는 네모 박스가 보인다.**
자체 검증이 통과한 이유는 **CSS만 봤기 때문**일 가능성이 높다 — 박스가 **JSX의 Tailwind 유틸리티 클래스**에서 오면 CSS 파일에는 흔적이 없다.

preview 화면에서 **F12 → Console** 열고 이 3줄을 붙여넣어라.

```js
const s = document.querySelectorAll('.pin-slot, [class*=pin-slot], [class*=pin-cell]')[0];
console.log('클래스속성:', s?.getAttribute('class'));
const c = getComputedStyle(s), b = getComputedStyle(s, '::before');
console.table({슬롯_배경: c.backgroundColor, 슬롯_테두리: c.border, 슬롯_라운드: c.borderRadius, 슬롯_그림자: c.boxShadow,
  before_생성: b.content, before_폭: b.width, before_라운드: b.borderRadius, before_테두리: b.border, before_배경: b.backgroundColor});
```

**판정표**

| 나온 값 | 원인 | 고치는 곳 |
|---|---|---|
| `클래스속성`에 `rounded-*`·`border`·`bg-*`·`shadow-*` 같은 Tailwind 유틸리티가 있다 | **JSX에서 온다** | **`PinGate.tsx`의 클래스 목록에서 그것들을 지운다** ← CSS만 고쳐선 안 없어진다 |
| 클래스는 `pin-slot`뿐인데 `슬롯_배경`이 투명이 아니다 | CSS에서 온다 | `PinGate.css`의 `.pin-slot` 규칙 |
| `before_생성`이 `none`이다 | **`::before`가 아예 안 만들어진다** = 동그라미가 없는 진짜 원인 | `PinGate.css`에 `.pin-slot::before` 규칙 신설 |
| `before_폭`이 `15px`가 아니다 | 크기만 틀렸다 | 값만 교정 |

## 2. 고칠 것

### 2-1. `PinGate.tsx` — 슬롯 div에서 박스 만드는 클래스를 지운다

슬롯을 그리는 부분을 찾아서 **클래스를 `pin-slot` 하나만 남겨라.**

```jsx
{/* ❌ 이런 형태면 (Tailwind가 박스를 만든다) */}
<div className="pin-slot w-11 h-12 rounded-lg border border-gray-300 bg-white/70 shadow-sm grid place-items-center">

{/* ✅ 이렇게 (클래스는 pin-slot 하나 · 스타일은 전부 CSS가 담당) */}
<div className="pin-slot" style={{ ['--i']: i }}>
  <input className="pin" type="password" maxLength={1} inputMode="numeric" autoComplete="off" ref={pins[i]} … />
  <svg className="dot-ring" viewBox="0 0 26 26" aria-hidden="true">
    <circle cx="13" cy="13" r="11" pathLength="100" />
  </svg>
</div>
```

- `style={{ ['--i']: i }}` 는 **반드시 유지**해라 — 성공 링의 0.1초 순차 지연(`calc(var(--i)*.1s)`)이 이 값으로 돈다.
- input에도 Tailwind 유틸리티(`border`·`bg-*`·`text-*`·`ring-*`·`focus:*`)를 붙이지 마라. 클래스는 `pin`만.
- **shadcn `Input`·`InputOTP` 컴포넌트를 쓰고 있으면 순수 `<input>`으로 바꿔라.** 그 컴포넌트들이 자기 테두리·포커스 링을 들고 온다.

### 2-2. `PinGate.css` — 슬롯·동그라미 규칙을 이 값으로 교체

```css
/* 슬롯 = 완전 투명한 42×48 자리. 배경·테두리·라운드·그림자 전부 없음 */
.pin-slot{
  position:relative;
  width:42px; height:48px;
  display:grid; place-items:center;
  background:transparent;
  border:0;
  border-radius:0;
  box-shadow:none;
}

/* ★ 보이는 동그라미 = 이 ::before 하나뿐. 빈 상태에도 항상 렌더된다 */
.pin-slot::before{
  content:'';
  position:absolute; left:50%; top:50%;
  width:15px; height:15px;
  box-sizing:border-box;
  border-radius:50%;
  border:1px solid #bbb;
  background:rgba(255,255,255,.55);
  opacity:.8;
  transform:translate(-50%,-50%);
  transition:background .18s ease, border-color .18s ease, opacity .18s ease, transform .18s ease;
}

/* 채운 상태 = 동그라미 자체가 인디고로 */
.pin-slot:has(.pin.filled)::before{ background:#4A4DE7; border-color:#4A4DE7; }

/* 입력 순간 = 0.34초 "통" 튀는 팝 */
.pin-slot:has(.pin.lit)::before{
  background:#4A4DE7; border-color:#4A4DE7;
  animation:pinDotPop .34s cubic-bezier(.34,1.56,.5,1);
}
@keyframes pinDotPop{
  0%{transform:translate(-50%,-50%) scale(.6)}
  55%{transform:translate(-50%,-50%) scale(1.25)}
  100%{transform:translate(-50%,-50%) scale(1)}
}

/* 실패 = 테두리만 빨강 (안은 빈 상태로 돌아간다) */
.pin-slot:has(.pin.err)::before{ border-color:#E24B4A; }

/* 숫자 = 완전 투명한 input. 아무것도 안 보인다 */
.pin{
  width:100%; height:100%;
  text-align:center; font-size:19px; font-weight:700;
  border:none; background:transparent;
  color:transparent; caret-color:transparent;
  outline:none; opacity:.8; padding:0; font-family:inherit;
}
.pin.lit{ color:transparent; }

/* 행 간격 7px */
.pin-row{ display:flex; gap:7px; justify-content:center; }
```

> `:has()`가 안 먹으면(구형 빌드 타깃) 슬롯 div 자체에 상태 클래스를 얹어서 `.pin-slot.is-filled::before`로 바꿔라. **동작만 같으면 된다 — 값은 위와 똑같이.**

### 2-3. `PinGate.css` — 힌트 링·성공 링 크기를 26px로

지금 링이 슬롯 전체를 감싸는 큰 원이다. **26×26으로 줄여라.**

```css
.dot-ring{
  position:absolute; left:50%; top:50%;
  width:26px; height:26px;              /* ← 여기가 핵심. 42~66px면 틀렸다 */
  transform:translate(-50%,-50%);
  pointer-events:none; overflow:visible;
  opacity:0;
}
.dot-ring circle{
  fill:none;
  stroke:#1A6B3C;                        /* 성공 = 초록 */
  stroke-width:2.2;
  stroke-linecap:round;
  stroke-dasharray:100;
  stroke-dashoffset:100;
  transform:rotate(-90deg);              /* 12시부터 시계방향 */
  transform-origin:50% 50%;
}

/* 첫 칸 안내 링 = 인디고. 입력 전까지 한 바퀴 그리고 0.3초 쉬고 무한 반복 */
.pin-wrap.hint1 .pin-slot:first-child .dot-ring{ opacity:1; }
.pin-wrap.hint1 .pin-slot:first-child .dot-ring circle{
  stroke:#4A4DE7;
  animation:pinHintLap 1.3s cubic-bezier(.5,.1,.4,.9) infinite;
}
@keyframes pinHintLap{
  0%{stroke-dashoffset:100;opacity:1}
  70%{stroke-dashoffset:0;opacity:1}
  84%{stroke-dashoffset:0;opacity:0}
  100%{stroke-dashoffset:100;opacity:0}
}

/* 성공 = 4칸 0.1초씩 순차 draw + 동그라미 살짝 튐 */
.pin-wrap.success .dot-ring{ opacity:1; }
.pin-wrap.success .dot-ring circle{
  animation:pinRingDraw .9s cubic-bezier(.5,0,.3,1) forwards;
  animation-delay:calc(var(--i,0)*.1s);
}
@keyframes pinRingDraw{ to{stroke-dashoffset:0} }
.pin-wrap.success .pin-slot::before{ animation:pinWin .5s ease calc(var(--i,0)*.1s); }
@keyframes pinWin{
  0%,100%{transform:translate(-50%,-50%) scale(1)}
  45%{transform:translate(-50%,-50%) scale(1.2)}
}
```

**SVG 마크업이 이 형태인지 확인해라** — `viewBox`와 `r`이 맞아야 26px 안에 들어간다.

```html
<svg class="dot-ring" viewBox="0 0 26 26" aria-hidden="true">
  <circle cx="13" cy="13" r="11" pathLength="100"></circle>
</svg>
```

## 5. ⛔ 이번에 하지 말 것

1. **v5에서 맞은 것을 다시 만들지 마라** — §0 ✅ 표 8항은 손대지 않는다.
2. **`src/index.css`를 또 정리하지 마라** — v5에서 이미 `.ym-pin-cell` placeholder 처리했다. 중복 작업이다.
3. **PinGate 전체 재작성 금지.** 이번 변경은 클래스 속성 정리 + CSS 3블록 교체다. 재작성하면 v5에서 맞춘 `0510` 통과·실패 초기화·자동 제출 로직이 다시 깨진다.

5. **새 색을 만들지 마라.** 이 화면 색은 `#4A4DE7` · `#1A6B3C` · `#E24B4A` · `#1A1A2E` · `#bbb` · `#D88455` 6개뿐.
