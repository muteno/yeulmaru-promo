## 2. 이번에 해야 할 일 (이 순서대로)

### STEP A — 데이터 배선 (가장 먼저, 여기서 막히면 멈추고 보고)

1. 첨부된 `예울마루_데이터.json`을 `src/data/yeulmaru.json`으로 **복사**한다.
   ⛔ **파일을 읽기 도구로 열지 마라** — 약 25만 토큰이라 컨텍스트가 터진다.
   구조는 `마스터명세.md` A부 §2에 전부 적혀 있으니 열어볼 필요가 없다.
   구조를 꼭 확인해야 하면 셸로만: `jq 'keys' src/data/yeulmaru.json`
2. `src/data/index.ts`를 만들어 named export한다:
   `records, programs, special, opsMaster, opsDaily, exhibMaster, exhibDaily, platforms, contents, applySettings, annual`
3. **건수를 콘솔에 찍어 아래와 맞는지 확인한다.**

| 키 | 기대 건수 |
|---|---|
| `records` | **137** |
| `programs` | 30 |
| `special` | 34 |
| `opsMaster` | 9 |
| `opsDaily` | 1477 |
| `exhibMaster` | 25 |
| `exhibDaily` | 11 |
| `annual.years` | 14 (2012~2025) |

→ 하나라도 다르면 **여기서 멈추고 무엇이 몇 건 나왔는지 보고해라.** STEP B로 넘어가지 마라.

### STEP B — 플레이스홀더 제거 + 앱 셸

1. `테스트 화면입니다.` / `오늘: …` 화면을 **삭제**한다.
2. 상단 내비 1줄을 만든다: 좌측 "예울마루", 중앙 메뉴 3개 = **`사업 실적` · `홍보 캘린더` · `프로그램`**.
3. 본문을 **좌우 2단**으로 나눈다(좌우 폭 1:1).
4. **PIN 통과 후 기본 화면 = 「사업 실적」**. 캘린더가 먼저 뜨면 안 된다.

### STEP C — 사업 실적 화면 (가장 중요 · 기본 화면)

`마스터명세.md` A부 §4-③과 B부(실측 DOM·스타일)를 따른다. 요약하면:

**좌측 「연간 실적」** — 데이터는 `annual`
- 헤더: 제목 "연간 실적" + 부제 "2012~2026.1Q" + 우측 **"누적 3,690,031명"**
- KPI 4칸(가로 1줄): `누계 관람·수강 1,505,706` · `최고 연도 (2019) 158,259` · `연평균 107,550` · `전년 대비 +2.6%`
- 「연도별 관람·수강 추이」 차트: x축 `annual.years`(2012~2025), 시리즈 3개 =
  공연(`#4A4DE7`) · 전시(`#D88455`) · 교육(`#1A6B3C`). 각 시리즈 값은 `annual.cats.<분야>.rows`에서 `key==='인원'`인 행의 `v` 배열.
- 「전체 실적표」: 열 = 2020·2021·2022·2023·2024·2025·누계 / 행 = 공연·전시·교육·계

**우측 「판매 현황」** — 데이터는 `programs` + `opsDaily` + `exhibDaily`
- ⛔ **`opsMaster`로 목록을 만들지 마라.** 9건짜리 구 마스터라 현재 판매 중인 공연이 전부 빠진다.
- 목록 = `programs`를 **공연/전시로 그룹**(머리글에 "● 공연 N" / "● 전시 N", 앞의 점 색 = 공연 인디고·전시 살몬)
- 표 열 = **`일자` · `프로그램` · `판매율` · `최근 7일 추이` · `사업 성격` · `장르`**
- 판매율 = `opsDaily`에서 해당 `공연ID`의 최신 `기준일자` 행의 `합계좌석` ÷ (`programs.회차` × 926) × 100
- `opsDaily`에 데이터가 없는 프로그램은 판매율 `—` + 추이 자리에 **"오픈 예정"**(목록에서 빼지 마라)
- 전시 행은 `exhibDaily`의 최신 `누계총인원`을 "누적 관객수"로 표시

### STEP D — 홍보 캘린더 화면

- 월간 그리드. `records`를 `날짜`별 뱃지로. 뱃지 텍스트 = `콘텐츠 제목`(없으면 `프로그램`)
- 뱃지 색 = `진행 상태`: 완료 `#1A6B3C` / 취소·반려 `#E24B4A` / 신청 중·보류 `#D88455` / 예정 `#4A4DE7`
- `special`은 회색 뱃지로 병기 · 셀에 3개 넘으면 "+N건 더보기"
- 첫 진입 월 = **2026년 6월**(데이터가 5~7월에 몰려 있다)

### STEP E — 프로그램 화면

- `programs` 카드 목록: `풀네임` · 기간(`시작일`~`종료일`) · `장소` · `담당자` · `콘텐츠구분` · `URL`(있으면 링크)
- 판매중 배지(오늘이 `판매시작일`~`판매종료일`) · `콘텐츠구분` 필터 칩

## 3. 지켜야 할 것 (어기면 다시 해야 한다)

1. **추측 금지.** 값이 필요하면 `마스터명세.md`에서 찾아라. 없으면 만들지 말고 "명세에 없음"이라고 보고해라.
2. **데이터 창작 금지.** 화면의 모든 숫자·이름은 첨부 JSON에서 온 것이어야 한다. 더미·예시 데이터를 넣지 마라.
3. **팀즈/Microsoft 로그인을 만들지 마라.** PIN `0510`이 유일한 관문이다.
4. **쓰기 기능(등록·수정·삭제·저장)을 만들지 마라.** 조회·검색·필터만이다.
5. **색은 팔레트만.** 이미 적용된 인디고·살몬 톤을 유지하고 새 색을 만들지 마라.
6. **날짜 변환 코드를 넣지 마라.** JSON 날짜는 이미 `"2026-05-23"` 문자열이다.
7. **점유율·판매율은 "목표 달성률"** 성격이다(100% 초과 가능). "좌석 점유율"이라고 쓰지 마라.
