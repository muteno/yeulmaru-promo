# 발행 없이 현재 상태 뽑는 진단 스니펫 (발행 비용 0)

> **왜 필요한가**: 발행(publish)은 관리자 승인이 필요해 비용이 든다.
> preview URL(`/service/coder/preview/…`)은 **로그인 벽(403)** 이라 원격에서 직접 못 읽는다.
> → 운영자가 **preview 화면에서 이 한 줄을 실행**하면, 원격(Claude)이 깃 정본과 대조할 수 있는
> 진단 결과가 클립보드에 담긴다. 그걸 채팅에 붙여넣기만 하면 된다.

## 사용법 (30초)

1. MISO **preview 화면**을 브라우저에서 연다(발행 안 해도 됨). PIN `0510`으로 들어가 대시보드까지 진입한다.
2. **F12** → **Console** 탭
3. 콘솔 입력창에 `allow pasting` 을 치고 엔터 *(크롬·엣지는 첫 붙여넣기를 막는다. 이 절차 없으면 아무 일도 안 일어남)*
4. 아래 블록 전체를 복사해 붙여넣고 엔터
5. 팝업이 뜨면 확인 → **결과가 클립보드에 자동 복사**됨 → 채팅에 붙여넣기

```js
(async()=>{const R={};const T=document.body.innerText||'';
const g=(o,p)=>{try{return p.split('.').reduce((a,k)=>a[k],o)}catch(e){return undefined}};
// 1) 데이터 건수 — 전역·모듈 어디에 있든 최대한 긁는다
const W=window,cand=['records','programs','special','opsMaster','opsDaily','exhibMaster','exhibDaily','platforms','contents','annual','rules','perfHistory','eduInstitutions','messages','managers'];
R.data={};for(const k of cand){const v=W[k]||g(W,'__DATA__.'+k)||g(W,'DATA.'+k)||g(W,'data.'+k);
 if(Array.isArray(v))R.data[k]=v.length;else if(v&&typeof v==='object')R.data[k]='obj:'+Object.keys(v).length}
// 2) 화면에 실제로 보이는 검증 숫자
R.kpi={'1,505,706':T.includes('1,505,706'),'3,690,031':T.includes('3,690,031'),'158,259':T.includes('158,259'),'107,550':T.includes('107,550')};
// 3) 화면 구조
R.dom={bodyLen:document.body.innerHTML.length,tables:document.querySelectorAll('table').length,
 svg:document.querySelectorAll('svg').length,canvas:document.querySelectorAll('canvas').length,
 inputs:document.querySelectorAll('input').length,buttons:document.querySelectorAll('button').length};
// 4) 메뉴·탭 텍스트
R.menus=[...document.querySelectorAll('nav a,nav button,header a,header button,[role=tab],[class*=tab]')].map(e=>(e.innerText||'').trim()).filter(Boolean).slice(0,20);
// 5) 팔레트 실측(화면에 실제 적용된 색)
const cs=new Set();for(const el of document.querySelectorAll('*')){const c=getComputedStyle(el);
 for(const p of ['color','backgroundColor','borderTopColor'])if(c[p]&&c[p]!=='rgba(0, 0, 0, 0)')cs.add(c[p])}
const hex=v=>{const m=v.match(/\d+/g);return m?'#'+m.slice(0,3).map(n=>(+n).toString(16).padStart(2,'0')).join(''):v};
const PAL=['#4a4de7','#d88455','#1a6b3c','#e24b4a','#1a1a2e','#fdf6f3','#e8e8fd','#6b6b7b','#888888','#ffffff'];
const used=[...cs].map(hex);R.palette={used:used.length,off:used.filter(h=>!PAL.includes(h)).slice(0,15)};
// 6) 라우트·제목
R.route={url:location.hash||location.pathname,title:document.title};
// 7) 화면 텍스트 앞부분(무엇이 보이는지)
R.screenText=T.replace(/\n{2,}/g,'\n').slice(0,1200);
// 8) 콘솔 에러 훅(이후 발생분 수집용)
W.__err=W.__err||[];if(!W.__errHooked){W.__errHooked=1;addEventListener('error',e=>W.__err.push(String(e.message).slice(0,120)))}
R.errors=W.__err.slice(0,5);
const out='```json\n'+JSON.stringify(R,null,1)+'\n```';
console.log(out);try{await navigator.clipboard.writeText(out);alert('진단 완료 — 클립보드에 복사됐습니다.\n채팅에 붙여넣어 주세요.')}catch(e){alert('클립보드 실패 — 콘솔 출력을 복사해 주세요.')}})()
```

## 원격(Claude)이 이 결과로 판정하는 것

| 진단 항목 | 정상값 | 어긋나면 |
|---|---|---|
| `data.records` | **137** | 데이터 미배선 또는 파싱 오류 |
| `data.programs` / `special` / `opsDaily` | 30 / 34 / 1477 | 〃 |
| `data.annual` | `obj:6` 이상 | 연간 실적 누락 |
| `kpi["1,505,706"]` · `kpi["3,690,031"]` | 둘 다 `true` | 사업 실적 화면 미구현 |
| `dom.tables` | 2 이상 | 전체 실적표·판매현황 표 누락 |
| `dom.svg`/`canvas` | 1 이상 | 추이 차트 누락 |
| `menus` | 사업 실적·홍보 캘린더·프로그램 포함 | 메뉴 구성 상이 |
| `palette.off` | 적을수록 좋음 | 팔레트 이탈(shadcn 기본색 잔존) |
| `screenText` | "연간 실적"·"판매 현황" 포함 | 기본 화면이 캘린더거나 미구현 |

## 이것 말고 다른 방법 (참고)

| 방법 | 가능? | 비고 |
|---|---|---|
| preview URL을 원격이 직접 read | ❌ | **403 로그인 벽**(실측). 발행본만 공개 |
| 발행본 URL read | ✅ | 원격이 curl 미러링 → 실렌더 → 13항 자동 대조(`tools/miso/verify_published.mjs`). **단 발행 비용 발생** |
| 위 콘솔 스니펫 | ✅ | **비용 0 · 즉시 · 권장** |
| MISO 코드 뷰(`<>`)에서 파일 복사 | ✅ | 코드 레벨 리뷰가 필요할 때(예: 판매율 계산식 확인) |
| 세션 쿠키를 원격에 전달 | ⚠️ | 기술적으로 가능하나 **세션 토큰 노출** — 권장하지 않음 |
| 스크린샷 | ✅ | 시각 확인엔 최고. 단 숫자 대조는 스니펫이 정확 |

**권장 조합**: 스니펫 결과(JSON) + 스크린샷 1장. 이 둘이면 원격에서 부족분을 정확히 짚어 다음 지시서를 만든다.
